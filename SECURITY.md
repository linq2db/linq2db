# Security Policy

## Reporting a vulnerability

Please report security issues privately, using either channel:

- email [security@linq2db.com](mailto:security@linq2db.com)
- [GitHub private vulnerability reporting](https://github.com/linq2db/linq2db/security/advisories/new)

Do not open a public issue, discussion or pull request for them.

Include, where you can:

- the affected package and version
- the database provider, if the issue is provider-specific
- steps or code to reproduce the issue
- the impact you expect
